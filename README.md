# CQR Print

Agente de impressão de etiquetas do **CQR System** para Windows. Fica num computador da fábrica,
busca as etiquetas no servidor do CQR System e entrega às impressoras (Zebra por ZPL; Argox, laser
e jato de tinta como imagem pelo driver do Windows).

Proposta e decisões: `docs/propostas/agente-de-impressao.md` no repositório `cqr-system-web`.
API usada: `docs/api.md`, seção 4.2, do mesmo repositório.
